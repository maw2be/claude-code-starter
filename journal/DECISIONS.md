# DECISIONS.md — Architecture Decision Records (ADR)

> Senior Dev zapisuje tu **decyzje architektoniczne/techniczne** podjęte zamiast pytania Stakeholdera.
> Dzięki temu Stakeholder może je później przejrzeć i ewentualnie zakwestionować, a zespół nie podważa raz podjętych decyzji bez powodu.

## Format
```
### ADR-XXX — <tytuł decyzji>  [YYYY-MM-DD]
- **Status:** Proponowana | Przyjęta | Zastąpiona przez ADR-YYY
- **Kontekst:** jaki problem / jakie opcje
- **Decyzja:** co wybrano
- **Uzasadnienie:** dlaczego
- **Konsekwencje:** plusy, minusy, koszt zmiany w przyszłości
```
