# SPRINT_LOG.md — Dziennik sprintów i tasków

> Główny dziennik pracy. Każdy sprint, każdy task, jego plan, status i wynik.
> Zespół czyta ostatni wpis na starcie sesji, by wiedzieć, gdzie skończył.

## Format sprintu
```
## Sprint <N> — <data> → <cel sprintu>

### Plan
FEATURE: ...
  TASK-XX: ... [P0] — status: TODO|IN_PROGRESS|REVIEW|DONE
    Kryteria akceptacji: [...]

### Dziennik prac
- [data godz] [ROLA] co zrobiono / jaka decyzja / co dalej

### Retrospektywa (wypełnia /retro)
- Dobrze: ...
- Źle: ...
- Wnioski: ...
```
